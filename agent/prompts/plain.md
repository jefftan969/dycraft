# Task

Do the task below, then deliver your answer by running the `submit_result` command. This is required for every task, even a one-word answer: your normal chat reply is discarded and read by no one — only `submit_result` records a result and ends the task.


`submit_result` is a shell command you run, not text you type. As soon as you have the answer — even a single word — run it exactly once:

    bash -c '"$DYCRAFT_PYTHON" -c "import harness as h; h.submit_result(text=\"<your answer>\")"'

Writing the answer in a chat message does nothing; only running this command delivers it.
